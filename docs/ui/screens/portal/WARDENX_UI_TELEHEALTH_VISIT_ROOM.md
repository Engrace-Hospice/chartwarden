## Purpose

Supports secure virtual hospice visits.

---

## Primary Users

- Patient
- Family caregiver
- Clinician

---

## Layout Pattern

Use Media Room.

```text
Video Area
Participant Panel
Visit Context
Chat / Notes
Controls
```

---

## Controls

- Join
- Leave
- Mute
- Camera
- Screen share if enabled
- Chat
- Call support

## Safety

Show urgent-care disclaimer and direct hospice phone number.

Clinician version should include:

- Visit documentation shortcut

- Connection quality

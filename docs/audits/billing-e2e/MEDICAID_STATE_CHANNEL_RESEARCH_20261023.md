# Medicaid state channels for hospice 837I - public-source research

**Date:** 2026-10-23 · **Status:** research notes, **not verified by any state or fiscal agent**. Gathered by five parallel
research passes over public web pages only (state Medicaid agencies, fiscal-agent and MMIS sites, companion guides). Where a
page could not be read (403, certificate error, unreadable PDF) the row rests on search-result excerpts and is marked in its
confidence. Several sources are old (the WA 837I guide is from 2012, the WY page from 2021, the MD guide from 2011).
Use this to prioritise outreach, not to claim a state is supported.

Plan: [`IMPLEMENTATION_PLAN_20261023.md`](./IMPLEMENTATION_PLAN_20261023.md) · Issues: [`ISSUES_20261023.md`](./ISSUES_20261023.md) (issue 1, issue 7)

## What the research says (51 jurisdictions: 50 states and DC)
| Finding | Count |
|---|---|
| Third-party clearinghouse submission explicitly allowed (all with trading-partner enrollment, most with testing) | 40 |
| Implied only (AL, CT, DC, MA, MO) | 5 |
| Not found (CA, ME, MS, NE, NJ) | 5 |
| No fee-for-service channel; runs through managed-care plans (TN) | 1 |
| Explicitly not allowed | 0 |

- **No state published a list of approved clearinghouses** that the researchers could read, apart from isolated mentions
  (RI names Change Healthcare; OK has a 2019 vendor-list PDF that was not read).
- **Hospice managed-care treatment** (carved in to Medicaid MCOs or fee-for-service) was found for only a few states (for
  example NY, OH, OK, TN, VA). For the rest it is not found. This matters because an MCO-paid hospice claim goes to the plan,
  not the state MMIS.
- **Oregon**: a clearinghouse must be listed on the provider's trading-partner agreement; this fits the existing
  Oregon gateway design, which uses a per-provider-entity credential.

## What this means for the design
1. "A clearinghouse accepts the claim" is never enough. Each state requires **trading-partner enrollment**, and many require
   **testing** before production. That is a per-state, per-agency onboarding step, not a code switch.
2. The research supports the capability-gate design in the plan: submission for a state is allowed only when that state has a
   recorded channel, the agency is enrolled, and testing has passed. States marked "not found" stay manual.
3. Because the clearinghouse role is usually allowed, the same `ClearinghouseTransport` can carry Medicaid for most states.
   Whether the chosen vendor is an accepted trading partner in each state is a vendor question (plan Track 4, issue 14),
   not something these public pages answer.
4. Managed-care hospice states need a separate path: the payer is the plan, so M41-style payer routing applies, not the
   state MMIS channel.

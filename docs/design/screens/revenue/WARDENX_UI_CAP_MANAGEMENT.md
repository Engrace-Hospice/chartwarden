# WARDENX_UI_CAP_MANAGEMENT

Version: 1.0  
Status: Screen Specification  
Module: Cap Management

---

## Purpose

Cap Management monitors hospice aggregate cap exposure, forecasts risk, and supports reporting.

---

## Primary Users

- Administrator
- Billing Manager
- Finance Staff
- Compliance Officer

---

## Layout Pattern

Use Dashboard.

```text
Page Header
Cap KPI Strip
Forecast Chart
Patient Contribution Table
Right: Risk / Assumptions / Actions
```

---

## KPI Cards

- Estimated Cap Liability
- Current Cap Usage
- Beneficiary Count
- Payments Received
- Forecast Variance

---

## Charts

- Cap usage over time
- Forecast vs threshold
- Payment trend
- High-contribution patients

---

## Tables

Columns:

- Patient
- Benefit period
- Payments
- Days
- Cap contribution
- Risk indicator

---

## Actions

- Refresh forecast
- Export report
- View assumptions
- Flag review
- Add note

# CHARTWARDEN_UI_PORTAL_CARE_TEAM_MESSAGES

Version: 1.0  
Status: Screen Specification  
Module: Portal Messages

---

## Purpose

This screen supports secure patient/family communication with the hospice care team.

---

## Primary Users

- Patient
- Family caregiver
- Authorized representative
- Hospice staff

---

## Layout Pattern

Use Conversation View.

```text
Conversation List
Message Thread
Right: Care Team / Response Expectations
```

---

## Message Types

- General question
- Symptom update
- Medication question
- Scheduling question
- Document question

---

## Safety Banner

Always show:

"For urgent or life-threatening concerns, call hospice directly or emergency services."

---

## Actions

- Send message
- Attach document/photo
- Request call
- View care team

# WARDENX_UI_STAFF_MANAGEMENT

Version: 1.0  
Status: Screen Specification  
Module: Staff Management

---

## Purpose

Staff Management controls users, employment/contractor status, disciplines, credentials, location access, and account status.

---

## Primary Users

- Administrator
- Office Manager
- HR/Admin Staff
- WardenX Ops

---

## Layout Pattern

Use Work Queue.

```text
Page Header
KPI Strip
Staff Table
Right: Staff Detail Panel
```

---

## KPI Cards

- Active Staff
- Pending Invites
- Credentials Expiring
- Inactive
- Locked Accounts

---

## Staff Table Columns

- Name
- Role
- Discipline
- Locations
- Status
- Credentials
- Last Login
- Actions

---

## Staff Detail

Sections:

- Profile
- Role / permissions
- Locations
- Credentials
- Schedule settings
- Security settings
- Audit history

---

## Actions

- Add staff
- Invite user
- Disable user
- Reset MFA
- Update role
- Add credential

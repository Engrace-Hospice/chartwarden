# WARDENX_UI_SUBSCRIPTION_BILLING

## Purpose

Subscription Billing manages WardenX customer billing, plans, invoices, payment status, and subscription lifecycle.

---

## Primary Users

- WardenX Ops
- Finance Admin
- Tenant Administrator where exposed

---

## Layout Pattern

Use Detail Page.

```text
Subscription Header
Plan Summary
Invoices
Usage
Payment Status
Actions
```

---

## Fields

- Plan
- Billing cycle
- Seats
- Locations
- Add-ons
- Invoice status
- Payment method
- Renewal date

---

## Actions

- Change plan
- Add seats
- View invoice
- Retry payment
- Cancel subscription
- Apply credit

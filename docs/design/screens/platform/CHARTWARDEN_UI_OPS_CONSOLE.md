# CHARTWARDEN_UI_OPS_CONSOLE

Version: 1.0  
Status: Screen Specification  
Module: ChartWarden Ops Console

---

## Purpose

The ChartWarden Ops Console supports internal platform administration, tenant support, system monitoring, feature flags, and safe support access.

---

## Primary Users

- ChartWarden Ops
- Support Admin
- Engineering Admin
- Security Officer

---

## Layout Pattern

Use Admin Console.

```text
Ops Sidebar
Tenant Search
System Overview
Tenant Detail
Right: Risk / Support Actions
```

---

## Sections

- Tenants
- System Health
- Feature Flags
- Support Sessions
- Integrations
- Billing/Subscribers
- Audit
- Incidents

---

## Tenant Detail

Shows:

- Organization
- Provider entities
- Locations
- Subscription status
- Feature flags
- Support history
- Integration status
- Risk indicators

---

## Actions

- View tenant
- Start audited support session
- Toggle feature flag
- View system status
- Open support ticket

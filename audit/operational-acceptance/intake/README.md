## Confirmed defects and corrections

1. **Tenant upload bucket absent for newly provisioned tenants.** Verified-upload now ensures the M22
   tenant bucket before creating the upload ledger/presign. Ownership remains M22.
2. **Authentication library error logging could include database parameters.** Better Auth's internal
   logger now drops bound argument objects and replaces an object-first message with fixed safe text,
   preventing error `params` from carrying session tokens into the structured log.
3. **WardenLens review footer occluded decision controls at constrained heights.** The intake page now
   uses the targeted task clearance and short-viewport footer behavior merged on main; this branch does
   not broaden that correction. Browser acceptance verifies actual hit targeting.
4. **The WardenLens BullMQ queue was absent from `/metrics`.** The composition root now explicitly adds
   its canonical queue name to the existing bounded queue-state gauge.
5. **Runtime Docker context included local scratch artifacts.** `scratchpad/` is excluded and held by a
   regression test.
6. **A CLI argument test inherited local database settings through Bun's automatic `.env` loading.**
   The child process now runs the absolute CLI path from a unique empty temporary directory, preserving
   its intended no-database boundary. The focused test and full non-live suite pass.
7. **At tablet/mobile widths the stacked DocLens source pane remained sticky and intercepted field
   decisions below it.** The source viewer now returns to document flow only when the workspace stacks;
   desktop side-by-side stickiness remains. The browser run performs and captures a real decision at
   375×812 and 768×1024.
8. **M22 document uploads had no production scanner adapter.** M22 now owns a clamd INSTREAM adapter,
   production boot requires its host configuration, and server, portal, onboarding and verified-upload
   paths fail closed when scanning is required. M36 ownership remains unchanged.
9. **A refused SUD detector with no rules evidence attempted an empty Drizzle update.** The worker now
   leaves the batch retryable at `classifier_complete`; the F236 live suite covers the refusal path.

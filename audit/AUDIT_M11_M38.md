# MODULE 11 — ORDERS

## GRADE: FAIL (3 BLOCKER / 8 MAJOR / 7 MINOR)

The spec is unusually complete and internally disciplined (explicit XState machine, command+cascade discontinuation, denylist scrubbing, eraser registration, strong test plan), but it fails on three architecture invariants: it rewrites the §20 dependency graph in a way that introduces a manifest cycle, its standing-order engine can execute clinical orders without any authenticated practitioner signature, and a worker performs forbidden cross-tenant PHI queries.

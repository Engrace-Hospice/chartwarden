# Billing Operations UX

The existing `/billing/operations` workspace now includes a responsive Claim.MD staging-health section. It shows attributed stage count, stages requiring attention, last persisted activity, state breakdown, source limitation text, loading/denied/error states, and a read-only retry.

The UI states that shared account polling, cursor values, and unattributed quarantine are restricted. It does not offer replay, resubmit, reset, release, or financial actions.

A central operator UI was not added; the restricted API is ready for the existing platform administration surface.

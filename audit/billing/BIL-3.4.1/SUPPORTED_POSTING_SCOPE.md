# Supported posting scope

No Claim.MD-originated financial scenario is enabled or certified by this phase. A staged ERA can be reviewed under existing nonposting M25 behavior. Manual/SFTP posting remains on the existing `receiveAdvice → m25.edi.835_received → postAdvice` path and was not modified.

One-claim payment, multiple-claim payments, PLB, reversals, recoupments, and line allocations are not newly supported for the Claim.MD staging path.

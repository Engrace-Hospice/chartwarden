The reproducible runner is `scripts/test-m25-835-ingestion-private.sh`. It requires the locally built `chartwarden-postgres:dev` image and starts a uniquely named, loopback-only disposable PostgreSQL container; no shared database URL is used. The image reports PostgreSQL 18.6. The live suite resets its disposable `public` schema and uses `chartwarden_app` (NOBYPASSRLS) for service operations.

The staged-ERA integration fixture is synthetic: one tenant/provider, one verified M41 claim identity, a fully paid $42.00 claim, no line/CAS/PLB/remark facts, and a synthetic payer UUID. It drives encrypted stage read → plan → distinct approval → explicit execution. Assertions cover exactly one M25 remittance line, tenant/provider and claim association, retained stage/plan source metadata, one claim-paid event and one advice-posted event, no effects during plan/approval, stale approval rejection, default-off gate refusal, cross-tenant/provider denial, rollback after M25 persistence but before posting-event commit, concurrent execution (one post, one idempotent result), and idempotent retry.

The final M25 run includes approval-without-effects, source-review revision invalidation, disabled-gate refusal, foreign tenant and provider denial, trigger-injected rollback after M25 persistence, concurrent execute (exactly one committed posting), and successful idempotent retry.

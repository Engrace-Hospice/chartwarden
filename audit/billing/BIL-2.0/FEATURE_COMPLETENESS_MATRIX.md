# Feature Completeness Matrix

Status terms describe repository evidence, not deployment certification: **Implemented and verified** = source path plus focused automated test coverage exists; **Implemented but incomplete** = a material domain path exists but end-user/external edge is unverified or absent; **Defective** = source demonstrates a concrete risk; **Not implemented** = no implementation found in the audited route/service surface; **Blocked by external dependency** = code deliberately fails closed pending external configuration/certification; **N/A** = domain does not own the behavior.

| Workflow step | M23 Medicare | M41 Commercial | M24 Medicaid |
|---|---|---|---|
| Identify claimable stay / payer scope | Implemented and verified: FFS primary + election window, service facts, provider scope. | Implemented and verified: commercial primary, patient caseload, admission/provider binding. | Implemented and verified: in-force Medicaid coverage, state/provider setup, claim attribution. |
| Assemble claim | Implemented and verified: server-derived TOB, claim lines and clinical snapshots. | Implemented and verified: server-derived institutional assembly and contracted rates. | Implemented and verified: state/control number, hospice and R&B lines subject to bound seams. |
| Required information validation | Implemented and verified: frozen rule registry, persisted runs/overrides. | Implemented and verified: payer-plan, enrollment, auth, freshness, rate and route gates. | Implemented and verified: shared/state rule registries and persisted validation. |
| Preview/render | Implemented and verified: 837I loader/render with typed gaps; UI has workbench/editor. | Implemented and verified: 837I renderer for ready claims. | Implemented but incomplete: Oregon local envelope render; production wire format is not verified and other states may deny. |
| User approval / send gate | Implemented and verified: submit requires ready state, permission, ABAC, step-up and version. | Implemented and verified: explicit ready and send-gate stages. | Implemented and verified: explicit submit state transition and route guard. |
